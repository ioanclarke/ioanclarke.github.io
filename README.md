This is a very basic static site generator that I use to generate my personal website.

Instructions:

1. Put common layout in `base.html` in `public` directory
2. Put pages you want (`index.html`, `projects.html` etc.) in `public/pages` directory
3. Put assets (images, CSS) in `public/assets` directory
4. Put posts in `public/posts` directory
5. Run `just deploy` - static site files will be outputted to `docs` directory
