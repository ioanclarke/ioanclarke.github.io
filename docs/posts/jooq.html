    The joys of jOOQ

    This is an appreciation of the excellent jOOQ library for JVM langauges

    Last updated: 2026-01-19

    I love jOOQ. In case you've not heard of it, here's the, in my opinion, very accurate, description of jOOQ from its website: "jOOQ generates Java code from your database and lets you build type safe SQL queries through its fluent API." This might be the understatement of the century. jOOQ might just be my favourite Java library - I use it everyday in work and after thinking about it for some time, I can only come up with a single issue with it. I feel like most other database-querying libraries try to reinvent SQL for some reason. You have ORMs, like Hibernate, which try to abstract the SQL away, which is all well and good until you realise you have to learn a second language to configure them. You have Spring Data JPA, which also tries to remove the need to write SQL, which works nicely until you need something more than a 'get by ID' or 'update by ID'.
